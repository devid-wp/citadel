## 🛠 Архитектура и Функционал

### 1. Безопасность и Криптография

* **Хэширование:** Авторизация через `bcrypt` (при отсутствии — фолбэк на `PBKDF2-SHA256`). Защита от перебора через экспоненциальную задержку.
* **Шифрование:** Симметричный алгоритм **AES-128-CBC + HMAC-SHA256** (Fernet). Поддерживает round-trip шифрование строк и файлов. Ключ генерируется через PBKDF2 (120 000 итераций). Поддерживается legacy XOR для старых конфигураций.
* **Аудит:** Встроенный анализатор уязвимостей системы (поиск debug-режимов, дефолтных учетных записей, открытых портов).

### 2. Сеть и Мониторинг

* **Сетевой стек:** Локальное ARP-сканирование (`netscan`), вывод конфигурации интерфейсов (`ip`), быстрый асинхронный `ping`.
* **Телеметрия:** `sysmon` (TUI-мониторинг CPU/RAM в реальном времени), `ps`/`kill` для управления процессами, анализ дисков (`df`, `free`).

### 3. Интеграция API (Без токенов)

* **Геолокация:** Определение провайдера, координат и города по внешнему IP.
* **Погода:** Интеграция с Open-Meteo. Текущие данные, почасовой прогноз на текущие сутки и сводка на 3 дня.

### 4. Интерфейс и Среда (UX)

* Автодополнение команд и путей по табу (**Tab**) через `readline` (`pyreadline3` на Windows).
* Навигация по истории команд (стрелки `↑` / `↓`) + локальный вызов `history`.
* Система динамических алиасов (`alias add ll ls`).
* 9 предустановленных цветовых схем (настройка через утилиту `center`).
* Быстрая блокировка сессии командой `lock` без завершения процессов оболочки.

## 🔒 Безопасность проекта

* **Безопасный парсинг:** Полностью исключен вызов небезопасного метода `eval()`. Обработка данных идет строго через `ast.literal_eval`.
* **Командный контекст:** Параметры в системные вызовы передаются без объединения строк, исключая возможность command injection. `shell=True` используется изолированно только для системных бинарников (`arp`, `ping`, `ipconfig`).
* **Изоляция данных:** Конфигурация пользователя (`system/user_config.json`) и логи (`system/citadel.log`) автоматически добавлены в `.gitignore`.
* **Фолбэки:** При отсутствии бинарных библиотек `bcrypt` или `cryptography` система автоматически переключается на безопасные стандартные модули Python (`hashlib`/PBKDF2).
