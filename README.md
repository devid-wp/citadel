# Citadel OS (v3.0)

Высокотехнологичная модульная консольная оболочка, написанная на языке Python и объединяющая инструменты системного администрирования, криптографической защиты данных, сетевого аудита и мониторинга ресурсов. Оболочка функционирует в средах Windows и Linux и минимизирует внешние зависимости, заменяя их встроенными архитектурными фолбэками.

##  Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
2. Инициализация сессииBashpython main.py
Аутентификация по умолчанию: Пароль admin (изменение учетных данных доступно через панель управления: center -> [3] Сменить пароль).🛠 Архитектурные компоненты и функционал1. Подсистема безопасности и криптографииМенеджер аутентификации: Проверка учетных данных осуществляется через хеширование bcrypt. При отсутствии бинарных зависимостей в системе реализован автоматический фолбэк на безопасный алгоритм PBKDF2-SHA256. Защита от брутфорса обеспечивается экспоненциальной задержкой между попытками ввода.Криптографический модуль: Реализовано симметричное round-trip шифрование строк и файлов по схеме AES-128-CBC + HMAC-SHA256 (Fernet). Деривация ключа выполняется через PBKDF2 (120 000 итераций). Для обеспечения обратной совместимости со старыми конфигурациями сохранен режим legacy XOR.Модуль аудита: Встроенный сканер уязвимостей локальной системы для поиска дебаг-режимов, дефолтных учетных записей и открытых портов.2. Сетевой стек и телеметрияСетевой интерфейс: Модули для низкоуровневого ARP-сканирования локальных подсетей (netscan), вывода конфигурации активных сетевых интерфейсов (ip) и асинхронной проверки доступности удаленных узлов (ping).Мониторинг ресурсов: Утилита sysmon (TUI-интерфейс для контроля нагрузки на CPU и RAM в реальном времени), встроенный менеджер процессов (ps/kill) и анализатор дискового пространства (df/free).3. Взаимодействие с API (Zero-Token)Геолокация: Определение сетевого провайдера, географических координат и города на основе внешнего IP-адреса.Погода: Интеграция с сервисом Open-Meteo. Вывод текущих метеорологических данных, почасового прогноза на сутки и сводки на 3 дня.4. Интерфейсная среда (UX)Интерактивное автодополнение команд и путей по нажатию клавиши Tab через библиотеку readline (pyreadline3 в среде Windows).Навигация по истории команд (↑ / ↓) с возможностью вывода полного журнала сессии через команду history.Система динамических псевдонимов (alias add <name> <command>).9 предустановленных цветовых схем терминала, настраиваемых через панель управления center.Блокировка текущего экрана командой lock без уничтожения активных дочерних процессов оболочки.📂 Структура репозиторияPlaintextcitadel/
